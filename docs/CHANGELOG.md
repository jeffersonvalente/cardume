[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

  a process sized to each change, hooks the model cannot skip) instead of counts; a Brazilian

- Architecture diagram as light/dark SVGs generated by `scripts/gen_architecture.py`.
- Three side-by-side recordings in `docs/assets/`, the same request with and without Cardume: a level-2

  and a force push stopped by the guard hook.
- Reference material moved out of the README into English docs: `docs/HOW_IT_WORKS.md`,

  `docs/OUTRAS_FERRAMENTAS.md`), `docs/EVALS.md`, `docs/CATALOG.md` (every agent, skill and manual

  in `README.pt-BR.md`.
- Marketplace and plugin descriptions are now in English.

## [2.0.0] - 2026-10-28

First public release.

### Added
- Seven Claude Code plugins in the `cardume` marketplace (`cardume-core`, `-frontend`, `-backend`,
  `-data`, `-platform`, `-qa`, `-games`) plus the `cardume-all` bundle: 33 agents, 62 skills and
  13 user-invoked commands.
- Proportional spec-driven delivery: work levels 0–3 classified automatically; `spec` → `tasks` →
  `implement` → `verify` → `review` for features; PRD → architecture → gate → release for products,
  with ADRs (MADR) at any level and an independent `qa-gatekeeper`.
- Hooks: syntax check after edits, security scan + lint on changed files before a turn ends,
  confirmation before destructive or public commands, write limits for the verifier, and a
  reminder for large changes without a spec or ADR.
- Safe project setup (`cardume-setup-project`): only a marked block of `CLAUDE.md` changes, with
  backups; `AGENTS.md` is imported, never written.
- `claude plugin eval` suites for every plugin and a CI workflow; a repository validator with
  18 checks.
- Skills follow the open Agent Skills format and can be installed in other tools.
